# ✦ Wania ✦
### Simple Scientific Calculator in Lavender Theme

A clean, minimalist, and aesthetically soothing scientific calculator named **Wania**, designed in a soft **Lavender** pastel colorway.

---

## 🌸 The Lavender Palette

- **Backdrop**: Gentle Lavender Mist (`#F4EFFA` → `#DCD0EE`)
- **Calculator Chassis**: Frosted Lilac-Lavender (`#EBE0F8` → `#D7C6EF` with border `#C5B0E5`)
- **Screen**: High-contrast Midnight Lavender-Plum (`#231834`) with glowing lilac-violet digits (`#EBDCFF`)
- **Number Buttons**: Marshmallow soft white (`#FDFBFF`) with deep violet typography (`#3B225D`)
- **Scientific Keys**: Pastel Lavender (`#E2D3F5`) with rich plum labels (`#4F2A79`)
- **Equals Button**: Vibrant Royal Lavender-Violet (`#8B5CF6`)
- **Clear Buttons**: Soft Rose-Lilac (`#D35E9E`)

---

## 🔬 Scientific Features (Simplified Layout)

- **Trigonometry**: `sin`, `cos`, `tan` with one-tap `DEG` / `RAD` angle toggle.
- **Powers & Roots**: Square root $\sqrt{x}$, square $x^2$, and exponentiation $x^y$ (`^`).
- **Logarithms**: Natural log `ln` and Base-10 log `log`.
- **Constants**: High-precision $\pi$.
- **Algebra**: Parentheses `(` and `)` with precedence evaluation.
- **Editing**: All Clear `AC` and Backspace `⌫`.
- **Keyboard Support**: Full physical keyboard typing support for laptop/desktop.

---

## 🚀 How to Run

1. **One-click**: Double-click `run.bat`
2. **Terminal**:
   ```cmd
   javac -d bin -encoding UTF-8 WaniaCalculator.java
   java -cp bin wanialavender.WaniaCalculator
   ```
